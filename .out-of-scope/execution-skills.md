# Execution skills from mattpocock/skills

Skills from mattpocock/skills that implement, test, or debug code are not adopted. That covers `implement`, `implement-spec`, `tdd` and `diagnosing-bugs`. Requests to adopt them, or any later upstream skill in the same class, are out of scope.

## Why this is out of scope

This repo uses mattpocock/skills for planning and superpowers for execution. The adopted skills from Matt's catalogue grill, research, prototype, model the domain, and turn a conversation into a spec, tickets, or a map of decisions. Once the plan exists, the superpowers skills take over: `writing-plans`, `executing-plans`, `subagent-driven-development`, `test-driven-development` and `systematic-debugging`.

Adopting an execution skill from Matt's side would give two skills the same trigger, and the user would have to name the skill each time. One source for each phase keeps the triggers clean.
